# CSE33101: Introduction to Algorithms

This repository contains implementations and reports for the CSE33101 Intro to Algorithms course.

- **Best Report Award** in Individual Assignment #1 (Sorting Algorithms)
- **Best Report Award** in Individual Assignment #2 (TSP Algorithms)

## 📁 Repository Structure

### [Assignment 1: Sorting Algorithms](./assignment%201)
Implementation and performance analysis of various sorting algorithms.
- **Algorithms:** Bubble, Selection, Insertion, Merge, Quick, Heap, Shell, Comb, Cocktail Shaker, Intro, Library, Tim, Tournament Sort.
- **Key Focus:** Time and memory complexity analysis across different input distributions (Random, Ascending, Descending, Partially Random).

### [Assignment 2: Traveling Salesperson Problem (TSP)](./assignment%202)
Solving the Traveling Salesperson Problem using various heuristics and algorithms.
- **Algorithms:** Nearest Neighbor, Convex Hull, MST-based, Held-Karp (Dynamic Programming), and a custom optimized approach.
- **Key Focus:** Optimizing the approximation ratio and execution time for large-scale TSP datasets.
